# Práctica CI/CD con GitHub Actions

Proyecto desarrollado para implementar y demostrar pipelines de Integración Continua (CI) y Entrega/Despliegue Continuo (CD) utilizando GitHub Actions.

## Tecnologías utilizadas

- Node.js
- Express
- Jest
- ESLint
- GitHub Actions

## Ejecución del proyecto

Instalar las dependencias:

npm install

Ejecutar la aplicación:

npm start

La aplicación estará disponible en:

http://localhost:4000

## Pruebas unitarias

Ejecutar las pruebas:

npm test

## Cobertura de código

Generar el reporte de cobertura:

npm run test:coverage

## Linting

Ejecutar el análisis de código:

npm run lint
